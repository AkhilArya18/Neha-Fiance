# The Life I Want to Build With You

A romantic photo story for Neha, built with React and Vite.

## Run locally

1. Install Node.js (LTS).
2. Run `npm install`.
3. Run `npm run dev` and open the local URL Vite prints.

## Build

Run `npm run build`. Vite creates the production site in `dist/`.

## Deploy to Vercel

Import this GitHub repository into Vercel. Vercel should detect Vite automatically. Use the project root as the Root Directory, `npm run build` as the Build Command, and `dist` as the Output Directory. No server-side functions are required for the static site.

The proposal and question forms use FormSubmit's AJAX endpoint. Confirm the activation email for the configured inbox and test form delivery before sharing the site. Submitted responses are sent to that third-party service and then emailed; do not request sensitive information.
